# Note 32: Backing up a tmpdrop link before it expires

A tmpdrop link is temporary by design, so treat the link itself as something worth saving until the file has been received.

## A simple habit

1. After uploading, copy the link into the same message or ticket where the recipient expects it, rather than leaving it only in the browser tab.
2. Note the expiry next to the link, for example: "Link valid for 24 hours, until Tuesday evening."
3. If the recipient has not downloaded the file by then, upload it again instead of asking them to retry a dead link.

## Why this matters

- The browser tab can be closed, the device can restart, and the link is then hard to recover.
- A recipient in another time zone may open the message after the link has already expired.
- Re-uploading is faster and clearer than troubleshooting a link that no longer exists.

## Tip

For anything that must stay available for weeks, tmpdrop is the wrong tool. Use permanent storage for the master copy and tmpdrop only for the quick, temporary handoff.
