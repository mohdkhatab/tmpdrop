# Note 44: Sharing tmpdrop links with people who have no account

Tmpdrop links work for anyone with the link. The recipient does not need an account, an app, or a login.

## What to tell the recipient

- "Just tap this link and the file will download. You do not need to sign up."
- Mention the file name and size, so they know what to expect.
- Mention the expiry: "This link works until tomorrow evening."

## If they are unsure

Some people are rightly cautious about links from strangers. If the recipient does not know you, or the file is unexpected, explain in your own words who you are and why you are sending it, in the same message as the link. Do not send a bare link with no context.

## Tips for less technical recipients

- Keep the message short and plain. Avoid jargon.
- Tell them where the file will go: "It will save to your Downloads folder."
- Offer help: "If it does not open, tell me what you see and I will send it another way."

## When an account is actually needed

If a file must be restricted to specific people, audited, or available long term, a temporary public link is the wrong tool. Use a service with proper access control instead.
