# Note 53: Keeping a record of the links you have sent

tmpdrop links expire, and that is the point — but once a link has expired, you may still want to know what you sent, to whom, and when. A small personal record solves that.

## What to write down

For each link you send, note four things:

1. **Date sent** — so you can tell how long ago it was, and whether the link is likely to have expired.
2. **File name** — so you can find the original again if someone asks for it.
3. **Recipient** — the person or group you sent it to, so you know who to contact if the file needs re-sending.
4. **Expiry date** — so you can answer "is the link still live?" without guessing.

## Where to keep the record

- A simple note or spreadsheet works fine. You do not need a special tool for this.
- Keep the record separate from the files themselves, and do not paste the full link into a shared document — the record is for you, not for everyone.
- If the files are sensitive, keep the record brief: file names and recipients only, without describing the contents.

## Why it helps

- **Re-sending is easy.** When someone says "I never got it" or "the link expired", you can check the date and recipient, then send a fresh link with confidence.
- **You avoid duplicates.** Without a record, it is easy to send the same file twice to the same person, or to forget someone entirely.
- **You can tidy up.** Every so often, look through the record and delete old entries for links that expired long ago and are no longer relevant.

## Tip

Write the entry at the same time you send the link, while the details are fresh. A record made later, from memory, is the one most likely to have the wrong date or the wrong recipient.
