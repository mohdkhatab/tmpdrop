# Note 47: Making shared tmpdrop files easier to use for everyone

Small choices make a shared file usable for more people, including people using screen readers, small screens, or slow connections.

## Use clear, descriptive names

A file named `report-final.pdf` is clearer than `doc1.pdf`. A message that says "the Q3 sales report" is clearer than "the file". Descriptive names help everyone, and they are essential for people who cannot see a preview thumbnail.

## Prefer readable formats

- Send text as a document or PDF with real text, not only as a photo of text. Photos of text cannot be searched, translated, or read aloud easily.
- If you must send an image of a document, add a short text summary in your message with the key points.
- Avoid tiny fonts and low-contrast colours in documents you share.

## Keep messages plain

Write the link message in plain language, with the file name, the expiry, and what to do next. Avoid relying on colour alone to convey meaning, such as "click the red link".

## Check the size

Large files are harder for people on slow or metered connections. Compress or split a file when you can, and warn the recipient when a file is large.

## Tip

Accessibility is not extra work for a special case. It is the same habit as clear naming and clear messages, applied consistently.
