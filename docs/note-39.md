# Note 39: Using tmpdrop on a mobile phone

Tmpdrop works in a mobile browser, but a few habits make it smoother.

## Uploading from a phone

- Choose the file from your photos, files, or downloads app. If the file is in a chat app, save it to Files first so you can find it again.
- Stay on the upload page until the link appears. Switching apps mid-upload can interrupt it.
- On a slow connection, prefer Wi-Fi for large files.

## Sharing the link

Copy the link and paste it directly into your message. Do not retype it by hand: a single wrong character breaks it.

## Downloading on a phone

- Tap the link, then wait for the download to finish before closing the browser.
- If the file does not open, check your Downloads folder. Many phones save it there even if no app opens automatically.
- For documents, open them from Files rather than from the browser preview when possible.

## Tip

If you share files from your phone often, keep a short checklist: right file, right expiry, link copied, recipient confirmed. It takes seconds and prevents most mistakes.
