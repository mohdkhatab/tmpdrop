# Note 40: When temporary sharing is not the right tool

Tmpdrop is made for quick handoffs. Some files need something else.

## Do not use temporary sharing for

- The only copy of an important document. If the link expires before anyone downloads it, the file is gone.
- Files that must stay available for months, such as a public resource page or a team handbook. Use permanent storage instead.
- Anything that needs access control, version history, or an audit trail. A link alone cannot provide those.

## Use it for

- A quick review copy: "Here is the draft, please look at it today."
- A one-off transfer between two people who are both online now.
- A large file that is too big for email but does not need to live anywhere permanently.

## A simple test

Ask: if nobody downloads this within a day, will it matter? If the answer is yes, store it somewhere permanent first, and only then share a temporary copy if that helps.
