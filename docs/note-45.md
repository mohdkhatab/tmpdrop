# Note 45: Writing a clear message to go with a tmpdrop link

A link on its own leaves the recipient guessing. A short message removes that guesswork.

## Include four things

1. What the file is: "This is the signed contract."
2. What they need to do: "Please download it and let me know you have it."
3. How long the link lasts: "The link expires tomorrow at 6 pm."
4. What to do if it fails: "If the link has expired, reply here and I will send a new one."

## Example message

"Hi Sara, here is the report we discussed: [link]. Please download it today if you can — the link expires tomorrow evening. Let me know once you have it, or if anything does not open."

## Keep it short

You do not need a long explanation. Two or three sentences with the file, the deadline, and the next step are enough. Long messages bury the link and the deadline, which are the two things the recipient needs most.

## Tip

If you send links often, keep a template for this message and fill in the file name and expiry each time. Consistency helps recipients know what to look for.
