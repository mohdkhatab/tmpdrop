# Note 48: Re-sending a tmpdrop link after it expires

An expired link is not a failure. It is a normal part of using a temporary sharing tool, and re-sending it well takes only a minute.

## What to say

Do not just paste a new link with no context. The recipient may not remember the first one, or may wonder why it changed. A short message helps: "Here is a fresh link for the report — the previous one expired yesterday. It works until tomorrow evening."

## What to check before re-sending

- Make sure you still have the original file, not only the expired link. If you deleted it, you cannot re-upload it.
- Check whether the file has changed since the first upload. If it has, say so: "This is the updated version, with the corrections from Tuesday."
- Choose an expiry that fits this recipient this time. If they missed a 1-hour link, a 24-hour link is more realistic than sending the same short expiry again.

## What not to do

- Do not keep sending the same expired link and asking the recipient to "try again". Once a link has expired, retrying it will not work.
- Do not send several new links at once for the same file. The recipient will not know which one to use, and you will not know which one they downloaded.

## Tip

If the same person repeatedly misses short expiries, agree a pattern in advance: send the link when they are online, or use a longer expiry for that person. A small adjustment saves repeated re-uploads.
