# Note 38: Organising files after receiving them from tmpdrop

A downloaded file is only useful if you can find it again later.

## Move it out of Downloads

Your Downloads folder fills up fast. As soon as you have checked a file, move it to the project folder, client folder, or documents folder where it belongs.

## Rename it while you remember

If the sender used a vague name, rename the file now, while you still know what it is. A month later, `download-3.pdf` tells you nothing.

## Keep a short note

For files that matter, add a line to your notes or task: where the file came from, who sent it, and what it is for. That context is easy to lose once the tmpdrop link has expired.

## Back up anything important

Tmpdrop is temporary storage, not a backup. If a received file is the only copy of something important, copy it to your regular backup or cloud storage straight away.
