# Note 36: What to do when a recipient cannot open a tmpdrop file

A failed download is usually a simple problem. Work through these checks in order before re-uploading.

## First, check the basics

1. Has the link expired? If so, upload the file again and send the new link.
2. Is the recipient using the full link? Links copied from a chat preview can be cut short.
3. Are they on a network that blocks downloads, such as a restricted office or school network? Trying mobile data or another network often answers this.

## Then, check the file itself

- Ask what happens when they click: nothing, an error page, or a partial download. Each points to a different cause.
- If the file is very large, suggest downloading on Wi-Fi and leaving the browser tab open until it finishes.
- If the file type is unusual, tell them which app opens it.

## Communicate clearly

Say what you have checked and what you changed: "I re-uploaded it with a 24-hour expiry; here is the new link." That avoids a loop of identical retries.
