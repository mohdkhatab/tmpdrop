# Note 35: Checking file size before uploading to tmpdrop

A quick size check prevents failed uploads and surprises for the recipient.

## Why size matters

- Large files take longer to upload and download, especially on mobile connections.
- Some recipients have limited storage or data, so a 500 MB video is a very different gift from a 5 MB document.
- If an upload keeps failing, size is the first thing to rule out.

## Before you upload

1. Look at the file size in your file manager.
2. If it is much larger than expected, check whether it contains something extra, such as an uncompressed video track or a full-resolution image.
3. Compress where it makes sense: a zipped folder, a resized image, or an exported PDF instead of a raw document.

## Tell the recipient

Mention the size in your message when it is large: "This is a 120 MB video, so download it on Wi-Fi." That one sentence prevents frustration and failed downloads.
