# Note 33: Choosing the right expiry for a tmpdrop upload

Tmpdrop offers several expiry presets. Picking the right one avoids both a link that dies too soon and a file that stays available longer than needed.

## Short expiries (minutes to an hour)

Use these for quick handoffs: a screenshot, a log snippet, or a file the recipient is waiting for right now. If they miss it, you can simply re-upload.

## Medium expiries (a day)

A day is a good default for most sharing. It covers different time zones and working hours without leaving the file up for a week.

## Long expiries (a week or more)

Reserve these for files people may need to come back to, such as a build or a reference document shared with a team. Even then, set a reminder to check whether the file is still needed.

## Rule of thumb

Choose the shortest expiry that still gives the recipient a realistic chance to download the file. Shorter is safer; re-uploading is cheap.
