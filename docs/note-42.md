# Note 42: Dealing with a slow tmpdrop upload

A slow upload is frustrating, but a few checks usually explain it.

## Check the obvious first

- Is the file much larger than you expected? A video or a folder of photos can be hundreds of megabytes.
- Are other apps using your connection at the same time, such as a cloud backup or a video call? Pause them if you can.
- Is your Wi-Fi signal weak? Moving closer to the router, or switching to a wired connection, often helps more than retrying.

## If the upload stalls

1. Wait a minute before cancelling. A progress bar that looks stuck can still be moving slowly.
2. If it has clearly stopped, refresh and try again once, rather than hammering retry.
3. If it still fails, compress the file or split it into smaller parts and upload those separately.

## Tell the recipient what to expect

For a large file, say so in advance: "This is a 300 MB file, so it may take a few minutes to upload and download." Setting that expectation avoids duplicate messages asking whether the link is ready.
