# Note 34: Naming files clearly before uploading to tmpdrop

The name a recipient sees is often the only context they get. A clear file name saves a round of questions.

## Before uploading, rename vague files

- `final-final-v2.pdf` becomes `project-report-march.pdf`.
- `IMG_4821.jpg` becomes `receipt-bookstore.jpg`.
- `data.csv` becomes `survey-results-2026.csv`.

## A naming pattern that works

Use lowercase letters, hyphens instead of spaces, and a date or topic where it helps: `invoice-2026-11-02.pdf`. Avoid characters that some systems treat specially, such as `#`, `?`, and `&`.

## Check before you share

Open the file once after renaming to make sure it is the right version. Renaming is quick; sending the wrong draft because two files looked alike is not.

## Tip

If several files belong together, say so in your message: "These three files are the report, the appendix, and the data sheet." The names plus one sentence remove most confusion.
