# Note 51: Downloading tmpdrop files on a shared or public computer

A file you download on someone else's computer stays there unless you remove it. Treat shared computers with extra care.

## Before you download

- Ask yourself whether you need to download the file here at all. If you only need to read it once, a preview in the browser may be enough.
- If the file is private — for example, a personal document or a work file — wait until you are on your own device if you can.

## After you download

1. Open the file, check it, and move it to your own storage (for example, a USB drive or your own cloud account) if you need to keep it.
2. Delete the downloaded copy from the shared computer's Downloads folder.
3. Empty the trash or recycle bin if the computer uses one, so the file is not simply sitting in deleted items.
4. Close any apps that opened the file, and sign out of any accounts you used in the browser.

## What not to leave behind

- Do not leave the browser tab open on the tmpdrop link. Anyone using the computer next could download the same file before the link expires.
- Do not save passwords or choose "remember me" on a shared computer, even if the browser offers to.
- Do not leave a copy in a recent-files list if you can clear it. Recent-files lists are an easy way for the next user to find what you opened.

## Tip

If you must use a shared computer regularly, keep a simple checklist: download, use, delete, sign out. Doing it the same way every time means you are less likely to forget a step.
