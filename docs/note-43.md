# Note 43: Keeping your original file after a tmpdrop upload

Uploading a file does not move it. It copies it. Keep the original anyway.

## Why keep the original

- The tmpdrop copy expires. Once it does, there is no way to get it back from the link.
- The recipient may lose their download, ask for it again, or need a different format. With the original, you can re-upload in seconds.
- Edits are easier from the original. If you only kept the shared copy, you would have to wait for the recipient to send it back.

## A simple rule

Do not delete a file from your own device just because you have uploaded it. Delete it only when you are sure you no longer need it, and it is backed up elsewhere if it matters.

## Where to keep originals

- In the project folder the file belongs to, not only in Downloads.
- In your regular backup, if the file is important. Tmpdrop is a sharing tool, not a backup service.
- With a clear name and date, so you can find it again without opening every file.

## Tip

After sharing, send yourself a quick note if needed: "Shared report.pdf via tmpdrop, original in Projects/Report/". That note saves a search later.
