# Installation

## Requirements

- Node.js 18 or later
- A Firebase project for storage and database

## Steps

1. Clone the repository: `git clone https://github.com/mohdkhatab/tmpdrop.git`
2. Install dependencies: `bun install`
3. Copy `.env.example` to `.env` and fill in your own values.
4. Start the app: `bun run dev`
