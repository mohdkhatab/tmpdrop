# Note 41: Zipping several files before uploading to tmpdrop

When you need to share more than one file, send them together as a single archive instead of a handful of separate links.

## Why zip first

- The recipient gets one link and one download, instead of tracking several links with different expiries.
- A zip keeps related files together, so nothing important is left out by mistake.
- Compressed files are often smaller, which helps on slow connections.

## How to do it well

1. Put the files in one folder and give that folder a clear name, such as `project-photos-november`.
2. Compress the folder (right-click and choose Compress, or use a zip tool).
3. Name the zip clearly too, for example `project-photos-november.zip`.
4. Upload the zip and tell the recipient what is inside: "This zip contains the report, the photos, and the data sheet."

## Watch out

- Some recipients cannot open unusual archive formats. Plain `.zip` is the safest choice.
- If the zip is password protected, share the password through a different channel, not in the same message as the link.
- Check the zip opens correctly before you upload it. A broken archive wastes everyone's time.
